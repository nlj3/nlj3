# Noel Jackson

I Tinker. I build tools that make IT work simpler and safer.

I work in IT operations, so most of what I build starts with a real problem: a task I was tired of doing by hand, or a failure I did not want to see twice. I like software that checks before it acts, keeps a record, and is honest about what it can and cannot do.

## Projects

### [Foreguard](https://github.com/nlj3/foreguard)

Shows you what an AI agent is about to do before it does it. Safe, read-only actions go straight through. Anything that would change a file, an account or a system is held and shown to you first, and it runs only when you approve it.

Written in Rust. Install with `cargo install foreguard`.
